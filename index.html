    Settings

    Textbooks

    When an assignment lists textbook problems (like "FPE 5.4"), each one is cropped from the textbook PDF. Textbooks are saved in this browser on this device only; nothing is uploaded.

    PrefixTextbookFile
    Add a textbook

    The prefix is what your class writes before the problem number. The first time a textbook is used it's indexed (a few seconds to a minute); after that it's instant.

    Problem headings

    For assignments that aren't textbook lists: a line starting with one of these begins a new problem. One regular expression per line. Used the next time you open a PDF.

    Pictures

    How to use HW Formatter

    1. Open PDF… (or drop the homework PDF on the page). Each problem is cropped and placed at the top of a sheet of engineering paper.
    2. Check the problem list. The red box on the original page shows what was cropped.
    3. Fill in or fix Name, Class, HW and Date. Untick Problem # in header to drop "P1".
    4. Export PDF gives one page per problem (more if a problem is long). PNGs (.zip) or Save PNG gives the problems as pictures you can move and resize, e.g. in Samsung Notes.

    Fixing things

    • Bigger/smaller: drag Problem size; Use this size for all applies it everywhere.
    • Wrong crop: drag a box on the original page, then Replace crop with box. Use ‹ › to change pages.
    • Add a piece from another page: drag a box, then Add box to this problem.
    • Split a problem: replace the crop with the first part, drag a box around the second part, then New problem from box.
    • Join or remove: Merge with next, Delete.

    Detection

    A problem starts at a line like HW#3.1, Problem 4 or Question 2 (change these in Settings). If none are found, each page is one problem. Scanned PDFs (no selectable text) become one problem per page; draw the boxes yourself.

    If the assignment lists textbook problems (1. FPE 5.26), add that textbook in Settings once and each problem is pulled from the book, under the assignment's own note for it. Anything after a line containing "optional" is skipped.

    Privacy

    Everything runs in your browser. Your PDFs are never uploaded. Name and settings are saved in this browser only.
